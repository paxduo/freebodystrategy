How to connect to Google Sheets
  1. Create or open a Google Sheet and ensure it has columns like Date, Property, Status, Hours, Activity, Notes.
  2. In Google Cloud Console, create an API key and enable the Sheets API.
  3. If you need to append rows, generate an OAuth token with the https://www.googleapis.com/auth/spreadsheets scope (or publish an Apps Script web app and paste its URL in the webhook field).
  4. Paste the Sheet ID, tab range, API key, and token here, then click “Load sheet data”.

All entries are persisted in your browser. When network updates fail, your local log remains intact and can be re-sent later.
